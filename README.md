# 🎙️ مُفرِّغ الصوت — Speech to Text (عربي / إنجليزي)

برنامج **ويندوز** يسمع تسجيلاتك الصوتية ويحوّلها إلى نص مكتوب **بالعربية والإنجليزية** بدقة عالية،
باستخدام نموذج الذكاء الاصطناعي **Whisper** الذي يعمل **محليًا على جهازك** — خصوصيتك محفوظة، ولا تحتاج إنترنت إلا عند تنزيل النموذج أول مرة وللترجمة.

![الواجهة الرئيسية](screenshots/main.png)

## 🚀 التشغيل السريع على ويندوز (الطريقة الأسهل)

### الخطوة 1: ثبّت Python (مرة واحدة فقط)
1. افتح الموقع الرسمي: https://www.python.org/downloads/ ونزّل أحدث نسخة (يفضّل 3.11 أو 3.12 أو 3.13).
2. شغّل المثبّت، و**أهم شيء**: فعّل في الأسفل خيار ✅ **Add python.exe to PATH** قبل الضغط على Install.

### الخطوة 2: شغّل البرنامج
- فكّ ضغط مجلد البرنامج، وادخل إليه، واضغط **نقرًا مزدوجًا على ملف `run.bat`**.
- أول مرة سيتثبّت كل شيء تلقائيًا (يحتاج إنترنت، قد يستغرق 3–10 دقائق بحسب سرعتك).
- عند أول تفريغ سيُنزَّل نموذج الذكاء الاصطناعي الذي تختاره (مرة واحدة فقط).

> 💡 جرّب فورًا: من البرنامج اضغط «اختيار ملف صوتي» واختر أحد الملفين التجريبيين من مجلد `samples`، ثم اضغط «تفريغ الملف إلى نص».

إذا ما بدك تثبّت بايثون على جهازك أصلًا: ارفع ملفات هذا المجلد كما هي إلى حسابك المجاني في GitHub، وسيبني لك سيرفر ويندوز من مايكروسوفت مثّبتًا جاهزًا **`SpeechToText-Setup.exe`** (ونسخة محمولة) تنزّلهما وتثبتهما مثل أي برنامج — بدون بايثون على الإطلاق.
الدليل المصوّر خطوة بخطوة: **[INSTALL_WITHOUT_PYTHON.md](INSTALL_WITHOUT_PYTHON.md)**

## 📦 تحويله إلى برنامج EXE مستقل (اختياري)

ادخل مجلد البرنامج واضغط **نقرًا مزدوجًا على `build_exe.bat`**.
بعد اكتمال البناء (بضع دقائق) ستجد البرنامج في:

```
dist\SpeechToText\SpeechToText.exe
```

خُذ مجلد `SpeechToText` كاملًا لأي مكان (سطح المكتب مثلًا) واعمل اختصارًا للملف التنفيذي.
ملاحظة: نموذج الذكاء الاصطناعي يُنزَّل عند أول تشغيل للنسخة التنفيذية أيضًا.

### تشغيل يدوي (للمطوّرين)
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## 📖 طريقة الاستخدام

### 🎙️ التسجيل من الميكروفون
1. اختر لغة كلامك: **تلقائي** (موصى به) أو العربية أو English.
2. اضغط **🔴 بدء التسجيل** وتحدّث بوضوح.
3. اضغط **⏹ إيقاف التسجيل** — سيُفرَّغ كلامك تلقائيًا ويُحفَظ التسجيل.
4. فعّل خيار **«تفريغ فوري»** إن أردت رؤية النص يظهر أثناء كلامك (النتيجة النهائية الكاملة أدقّ دائمًا).

### 📁 تفريغ ملف جاهز
1. اضغط **«اختيار ملف صوتي»** واختر المحاضرة/المقابلة/البودكاست.
2. يمكنك **▶ تشغيله** للاستماع داخل البرنامج.
3. اضغط **«تفريغ الملف إلى نص»** — يظهر النص تدريجيًا مع شريط تقدّم.
4. فعّل **«إظهار الطوابع الزمنية»** إن أردت توقيت كل جملة.

### 🌐 الترجمة
- انتقل لتبويب **«الترجمة»** واضغط **«ترجمة تلقائية»**: إن كان النص عربيًا يُترجم للإنجليزية والعكس. يمكنك أيضًا اختيار الاتجاه يدويًا، ثم نسخ الترجمة أو حفظها.

![تبويب الترجمة](screenshots/translate.png)

### 💾 النسخ والحفظ والسجل
- **نسخ النص**: لصقه في وورد أو واتساب ويب أو أي مكان.
- **حفظ TXT / Word**: مستند جاهز للتحرير والمشاركة (العربي يُحاذى لليمين تلقائيًا في Word).
- **حفظ SRT**: ملف ترجمة بتوقيتات جاهز لرفعه مع فيديوهات يوتيوب.
- **السجل**: كل تفريغ يُحفظ تلقائيًا؛ انقر نقرًا مزدوجًا على أي عنصر لاسترجاعه مع ترجمته وملفه الصوتي.

## 🧠 أي نموذج أختار؟

| النموذج | الحجم | مناسب لـ |
|---|---|---|
| `tiny` | 75 MB | تجربة سريعة فقط — دقة ضعيفة بالعربية |
| `base` | 145 MB | أجهزة قديمة، كلام واضح وقريب |
| **`small`** ✅ | 490 MB | **الافتراضي والموصى به: توازن ممتاز سرعة/دقة** |
| `medium` | 1.5 GB | أعلى دقة للمحاضرات واللهجات — يحتاج جهازًا قويًا وصبرًا |

---

## 🎯 نصائح لأفضل دقة بالعربية واللهجات

1. **سجّل قريبًا من الميكروفون** (20–30 سم) في مكان هادئ — هذا العامل الأهم.
2. إن كانت **اللهجة قوية** (عامية أردنية/مصرية/خليجية...) اختر اللغة **«العربية»** يدويًا بدل تلقائي، ويفضّل نموذج `medium`.
3. للملفات الطويلة جدًا (أطول من ساعة) قسّمها إلى أجزاء لتوفير الذاكرة والوقت.
4. الصوت النقي أصلًا (تسجيل جوال واضح) يعطي نتائج أفضل بكثير من تسجيل قاعات بصدًى.

## 🔒 الخصوصية ومكان بياناتك

- التفريغ يتم **على جهازك 100%**؛ لا يُرفع صوتك لأي خادم.
- الإنترنت يُستخدم فقط لـ: تنزيل النموذج أول مرة، وخدمة الترجمة عند طلبها (يُرسَل النص فقط).
- السجل وتسجيلات الميكروفون محفوظة في: `C:\Users\اسمك\.speech_to_text`
- النماذج المُنزّلة محفوظة في: `C:\Users\اسمك\.cache\huggingface`

## 🛠 حل المشاكل الشائعة

| المشكلة | الحل |
|---|---|
| «لم يتم العثور على Python» في `run.bat` | ثبّت Python من python.org وفعّل **Add to PATH**، أو أعد التثبيت واختر Modify ← Add to PATH |
| الميكروفون لا يعمل | الإعدادات ← الخصوصية والأمان ← الميكروفون ← فعّل «السماح للتطبيقات بالوصول»، وتأكد أن الميكروفون الصحيح هو الافتراضي في إعدادات الصوت |
| أول تشغيل بطيء | طبيعي: تثبيت المكتبات + تنزيل النموذج يحدثان مرة واحدة؛ بعدها التشغيل فوري |
| التفريغ بطيء على جهازي | جرّب نموذج `base`، وأغلق البرامج الثقيلة؛ سرعة التفريغ تعتمد على المعالج |
| النتيجة فارغة | الصوت صامت/خافت جدًا، أو اختر اللغة يدويًا، أو جرّب نموذجًا أكبر |
| الترجمة تفشل | تحقق من الإنترنت؛ البرنامج يجرّب خدمتين (Google ثم MyMemory) وفي حالات الازدحام أعد المحاولة بعد دقائق |
| لا أسمع تشغيل ملف M4A/MP4 | التشغيل داخل البرنامج لا يدعم بعض التنسيقات، لكن **التفريغ يعمل عليها عادة**؛ اسمعها بأي مشغّل خارجي |
| تحذير ويندوز عند تشغيل EXE | اضغط «مزيد من المعلومات» ← «التشغيل على أي حال» (التحذير يظهر لأي برنامج غير موقّع رقميًا) |

## 🗂 بنية المشروع

```
app.py            الواجهة الرئيسية (PySide6 / Qt)
transcriber.py    محرك التفريغ (faster-whisper)
recorder.py       التسجيل من الميكروفون والتشغيل
translator.py     الترجمة عربي ⇄ إنجليزي (مزودان مع بديل تلقائي)
history.py        حفظ السجل والتسجيلات
cli.py            أداة سطر الأوامر
run.bat           تشغيل بنقرة مزدوجة (يثبّت كل شيء تلقائيًا)
build_exe.bat     بناء نسخة EXE مستقلة
samples/          ملفا صوت تجريبيان (عربي + إنجليزي)
```

يعتمد على مشاريع مفتوحة المصدر: **OpenAI Whisper** عبر **faster-whisper**، وواجهة **Qt (PySide6)**.
